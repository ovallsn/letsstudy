# LetsStudy Play listing assets

Run `scripts/generate-play-assets.ps1` on Windows to regenerate these PNGs from the repository-owned logo and demo screenshots. The source images are `docs/letsstudy-icon.png` and `docs/screenshots/`. No third-party graphic assets are used. The 512×512 store icon, 1024×500 feature graphic and eight 1242×2208 phone screenshots are produced in `play-listing/`; screenshots are 24-bit PNG without alpha and retain the complete app UI within Play's portrait aspect ratio.

The age screen and both youth lesson routes were captured from isolated Android emulator users; the adult demo screenshots came from the existing repository. Check all images against the final signed build and never upload screenshots containing a real account or personal data.
